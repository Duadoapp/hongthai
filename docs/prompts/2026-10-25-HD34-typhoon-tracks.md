- **只轉載官方路徑與暴風圈**：台灣附近用中央氣象署開放資料、境外用日本氣象廳，**都標出處**；HongThai 不自己算任何路徑或時間

## 1. 做什麼

- 每報抓：氣象署 `W-C0034-005`（以 API 文件為準；目前位置、過去路徑、預報點、70% 機率圈、7 級／10 級暴風半徑）；日本氣象廳的颱風資訊
  （現報已在用的端點；目前位置、預報點、予報円、暴風警戒域、強風域）
- **選哪一份**：每個颱風，氣象署有發布就用氣象署（台灣附近），沒有才用日本氣象廳；同一顆兩邊都有時只放氣象署那份並在 `others` 記日本氣象廳有
  （不畫兩條）——PR 說明寫清楚怎麼對同一顆（編號、名稱、位置）
- **範圍**：任一颱風的目前位置或任一預報點落在地圖框（51 個機場的經緯度外擴 5 度，寫成常數）內才算「範圍內」
- 輸出 GitHub Pages `typhoons.json`（只放最新一份）：`generatedAt`、`active`（範圍內有沒有）、`storms[]`：`id`、`name`（四語：氣象署給中文、
  日本氣象廳給英文名，缺的照現有命名規則）、`source`（`cwa`／`jma`）、`issuedAt`、`url`（官方頁面）、`past[]`、`now`、`forecast[]`（時間、位置、
  機率圈半徑、暴風半徑——**原文的數值與單位照存**，換算只換單位並註明）；沒有颱風時 `active: false`、`storms: []`
- **原文照轉載**：不平滑、不內插、不延伸；資料舊（`issuedAt` 超過 12 小時）就標 `stale: true`
- 失敗只 log，不影響 `latest.json`；`latest.json` 只在 `sources` 加兩個出處（只加不改名）
