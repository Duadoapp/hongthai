# HD1：每個機場一張分享預覽圖（og/<iata>.png）

模型：Opus，強度高。規格是 Duado #374 定的（Shawn 2026-10-18 轉述）；這支只加輸出，不碰 `latest.json`。

先讀 `docs/ORCHESTRATOR.md`（定位、階段清單 HD1 那條）、`README.md`、`src/hongthai/build.py`（`publish()`、
`Timing`、`BUDGET_S`）、`src/hongthai/assess.py` 開頭（等級）、`airports.json`。

## 規格（Duado #374 定案）

每報 build 跑完，用 **Pillow** 畫每個機場一張 **1200×630** 的分享預覽圖，發布到 GitHub Pages 的
`og/<iata>.png`（iata **小寫**，例如 `og/tpe.png`）。內容：IATA 大字、機場名（zh-TW＋en）、燈號
（AI 上線前一顆規則燈，上線後自動變三顆）、更新時間、HongThai 字樣。字型由 hongthai 自備（OFL 授權的中日韓
字型放在 repo，附授權檔）；Duado 用 Pages Function 轉送這張圖，網址格式他們知道，`latest.json` 不用加欄位。

## 預設值（Shawn 2026-10-19 拍板；1、5、6、7 照主對話原案，2、3、4 改成和 Duado 網頁一致）

1. **燈號代表什麼**：這個機場**未來 5 天（20 格）裡最高的等級**；旁邊一行小字寫第一個達到那個等級的格的
   當地日期時段，例如「最高：高　10/23 14–20 時」；全部低就寫「未來 5 天：低」。`confirmed` 的格視為高，
   並寫「已確認停飛」；全部 `unknown` 時寫「資料不足」
2. **燈的顏色與形狀（Duado 晨光色）**：低 `#C2DCC6`（sage）、中 `#F3E3A5`（butter）、高 `#F7C9A9`（apricot）、
   已確認 `#263038`（text）、資料不足 `#D8DEE3`（mapIdle）。這幾個顏色淡，**燈不是小圓點，是大圓角色塊**
   （例如 300×110，圓角 28），裡面置中寫等級字（「低」「中」「高」「已確認」「資料不足」，zh-TW），字色 `#263038`
   （已確認那塊底色是深的，字用 `#EDF1F4`）。顏色集中寫在一個 dict
3. **底色與文字（Duado 晨光風格）**：底色 `#EDF1F4`（background）、文字 `#263038`（text）；**大圓角色塊、不用框線、
   不用陰影**；不做深色版
4. **字型（Duado 品牌字型，都是 SIL OFL 1.1）**：中文用**芫荽 Iansui**（<https://github.com/ButTaiwan/iansui>）；
   英文與數字用 **Fraunces**（<https://github.com/undercasetype/Fraunces>），**SOFT 軸開到最大（最圓）、字重 600
   的靜態檔**（用 fontTools `varLib.instancer` 從可變字型產生：`{"SOFT": 100, "wght": 600}`，`opsz` 留預設；
   產生的靜態檔也是 OFL）；**Noto Sans TC**（Google Fonts，OFL）只當芫荽缺字時的備援。
   Pillow 不會自動補字，所以畫文字時要**逐字分段**：ASCII 與數字 → Fraunces；其他字先查芫荽的 cmap 有沒有，
   沒有才用 Noto（用 fontTools 讀 cmap，一次做成集合）。三套都**只放子集**進 repo（`assets/fonts/`：
   `Iansui-Regular.subset.ttf`、`Fraunces-Soft600.subset.ttf`、`NotoSansTC-Regular.subset.ttf` 與 Bold 如有需要），
   每套各自的 `OFL.txt`，`assets/fonts/README.md` 寫來源、版本、怎麼重做；重做腳本 `tools/make_font_subset.py`
   （讀 `airports.json` 的 zh-TW 名稱、地區名、固定字串、數字、ASCII、全形標點、`–`／`・`，完整字型下載到暫存
   目錄、不進 repo）。**測試**用 fontTools 檢查「每個需要的字，芫荽或 Noto 子集至少一個有；ASCII 與數字 Fraunces
   子集都有」（之後加機場沒重做子集，CI 會紅）
5. **版面**（1200×630，邊距 64）：左上 IATA 大字（Fraunces，約 160 px）；其下機場名 zh-TW（芫荽 56）＋ en
   （Fraunces 36）；右上燈號色塊（第 2 點；之後三顆時並排、各自上方標「規則」「Claude」「Gemini」，寬度自動排）；
   色塊下方那行小字（第 1 點）；左下「更新 2026-10-19 02:15（當地時間）」（28，用該機場的時區顯示 `generatedAt`）；
   右下「HongThai　機場停飛風險」（32）＋ 一行小字「duado.app/hongthai」。不放 logo、不放地圖
6. **三顆燈的擴充**：畫圖的函式吃一個 `lights: list[Light(label, level, note)]`，現在只傳一顆（規則燈，`label`
   省略不畫）；AI 對決那支只要多傳兩顆，版面自動變三顆
7. **產出與失敗處理**：在 `publish()` 之後、Pages 上傳之前畫，寫到 `public/og/<iata>.png`；**不進 `data` 分支**
   （每報重畫，不留歷史）。畫圖失敗只 log、不讓 build 失敗；`history/timing/` 加一行 `source: "og"`
   （`ok`、`seconds`、`bytes` 是 51 張的總大小）；預算 60 秒（`BUDGET_S["og"]`）。整次 build 失敗改發布上一份
   `latest.json` 時，也用那份重畫（和 `publish(prev)` 同一條路）
8. **PNG 大小**：目標每張 ≤ 60 KB（淺底、少色，`optimize=True`；需要的話轉成調色盤模式）。51 張約 3 MB，
   Pages artifact 可以接受
