# HD15c：WeatherNext 3 旁觀等級上傳 Cloudflare R2（只有等級、不放數值）

模型：Sonnet，強度高。`latest.json`、`data` 分支、Pages **都不能出現 WN3 的等級或數值**；只多一個寫 R2 的步驟。網頁是 Duado HW23、轉送是 Duado 總指揮。

先讀：`docs/worklog/2026-10-28.md`（Google 回信、Shawn 00:15–00:17 定案）、`docs/worklog/2026-10-26.md`（WN3 定案）、`docs/ORCHESTRATOR.md` 的 HD15 段、
README「WeatherNext 3 的條款」、`wn3report.observe_private`、`wn3private.py`、`config.WN3_MODE`、`build.py` 裡 `private` 那段。

## 背景與定案

- 條款：看不出原始數字的加值（Non-Retrievable VAS，例如只有等級）**可以公開**，要附 Section 4(b) 的出處與免責；**不能在限制國家提供**（日本、南韓、印尼、
  古巴、伊朗、北韓、克里米亞、頓內茨克、盧甘斯克）。Google 10/28 回信：日本、南韓不給書面同意
- Shawn 10/28 定案：**現在先做**（服務帳號還讀不到 WN3，先用假資料寫好，讀得到就自動上線）；**51 個機場都上傳**（日本、南韓的機場照樣有），
  擋限制國家的**訪客**由 Duado 的轉送程式看 Cloudflare 的訪客國家做（不在這支）
- WN3 **不投票、不進 `latest.json`**（照舊）

## 1. 做什麼

- `private` 模式算完那一報（`observe_private`，`stored == "written"` 或這一報剛查過）之後，另外產生**只有等級**的檔，上傳 R2：
  - 物件 `wn3/<iata 小寫>.json`（51 個，只放最新一份，覆寫）：

        {"schema": 1, "generatedAt", "run", "model": "wn3",
         "attribution": "<Section 4(b) 原文＋取得管道（Google Cloud Storage 或 BigQuery，照實際 via）>",
         "slots": [{"from", "to", "level": "low"|"medium"|"high"|null,
                    "levels": {"wind", "rain", "snow", "fog"}} × 20]}

    格子同 `latest.json` 的 6 小時格（0–120 小時）；**不放** `windKt`、`gustKt`、雨量、`p49Kt` 或任何數字（測試擋：檔裡除了時間與 schema 以外不能有數字）
  - 這一報 WN3 失敗、或 bucket 裡沒有這一報：**不上傳**（R2 留著上一份，網頁由 `generatedAt` 判斷舊不舊）
- R2 用 S3 相容 API：secrets `R2_ACCOUNT_ID`、`R2_ACCESS_KEY_ID`、`R2_SECRET_ACCESS_KEY`，bucket 名稱 `R2_BUCKET`（Variable，預設 `hongthai-wn3`）；
  套件盡量用現有的（沒有 S3 套件就用 `requests`＋自己簽 SigV4，或加 `boto3`——加套件要在 PR 說明寫理由與安裝時間）。沒設 secrets 就跳過、記 `sources.wn3.r2`
  為 `not_configured`
- `sources.wn3` 多 `r2`（`ok`／錯誤碼、上傳幾個檔），**只有中繼資料**
- **日誌**：只印上傳幾個檔、bytes、錯誤碼，不印等級（等級雖然不是原始數字，日誌是公開的、會在限制國家被看到）

## 2. 測試

- 等級檔格式、51 個機場都有、檔裡沒有任何預報數字、出處文字照 via
- WN3 失敗或沒查到不上傳；沒設 secrets 跳過；R2 失敗只記錯誤碼、整報照出
- `latest.json`、`data` 分支、Pages、日誌都沒有 WN3 的等級（延用 HD15b 的測試寫法）
