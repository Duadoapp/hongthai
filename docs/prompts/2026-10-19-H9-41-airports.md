## 要做的事

### 1. `airports.json`

每個機場：`icao`、`iata`、`tz`（IANA）、`region`（上表 id）、`name`（四語）、`lat`／`lon`（機場參考點）、`runways`
（真北方位，見第 2 節）、`warningSources`、`cwaAreas`（台灣機場）、`thresholds`（全部用 HD2 之後的預設，
不覆寫；機場物件可以省略 `thresholds` 讓程式用預設，若現在不支援省略就把預設抄進去）。

- 四語名稱照現有五個的風格：短名、不加「機場」兩字（例：`桃園`／`桃园`／`Taoyuan`；`上海浦東`／`上海浦东`／
  `Shanghai Pudong`；`關西`／`关西`／`Kansai`；`馬祖南竿`／`马祖南竿`／`Matsu Nangan`；`濟州`／`济州`／`Jeju`）。
  zh-HK 用香港慣用字（例：`沖繩` 兩地同、`新千歲` 同；差異多在簡繁與個別用字，不確定就和 zh-TW 一樣）
- `warningSources`：台灣十個 `["cwa"]`、香港 `["hko"]`、澳門 `["smg"]`，其他**空陣列**（日本、韓國的官方警報是
  之後的 HD）。
- `cwaAreas`（氣象署警戒區關鍵字，**每個機場一組**）：桃園、松山維持現在的；高雄 `["南部", "高雄"]`；
  台中 `["中部", "臺中", "台中"]`；台南 `["南部", "臺南", "台南"]`；花蓮 `["東部", "花蓮"]`；台東 `["東部", "臺東", "台東"]`；
  澎湖 `["澎湖"]`；金門 `["金門"]`；馬祖 `["馬祖", "連江"]`。請對一下氣象署 `W-C0034-001` 警戒區的實際用語
  （`tests/fixtures/cwa_w-c0034-001_land.json` 有一份），有不同就改

### 2. 跑道方位

- 現有五個機場維持 README「跑道方位」表的 AIP 值，不動
- 其他 36 個用 **OurAirports** 的 `runways.csv`（<https://ourairports.com/data/>，公有領域／Unlicense）：
  `le_heading_degT`／`he_heading_degT` 是真北方位；平行跑道同方位記一組；關閉的跑道（`closed=1`）不要；
  沒有方位的機場 `runways: []`（側風就是 `null`，現有機制）。`airports.json` 每個機場加 `runwaySource`
  （`"aip"` 或 `"ourairports"`）備查
- 抽查五個（例如 ZSPD、RJTT、RKSI、ROAH、RCMQ）跟維基百科或該國 AIP 的跑道號碼是否一致，結果寫進 README
  「跑道方位」表（新機場合成一句「其餘 36 個取自 OurAirports，抽查 ○○ 五個一致」，不用逐個列）
- README「資料來源與授權」加 OurAirports 一列

### 3. 來源

- **TAF／METAR**：`taf.py` 一次請求帶所有 ICAO（AviationWeather Data API 的 `ids` 可以逗號分隔），確認網址長度
  沒問題。部分小機場沒有 TAF（可能：馬祖、金門、澎湖、台東、花蓮；請實際查），沒有就該機場
  `taf: null`、官方層只剩 METAR 與警報（現有機制），README 列出哪些機場沒有 TAF
- **ECMWF／GFS（AWS）**：都是全球檔抓點，機場數增加只多解析幾個點，不用改抓法；確認 `grib.read_points`
  對 41 個點的效能沒問題
- **GFS 的 NOMADS 備援**：`groups()` 用經度差 3° 分框，41 個機場會分成很多框；改成**一個框**涵蓋全部
  （北緯 17–44°、東經 107–147°，含 1° 邊距）或依地區六個框，擇一並說明理由
- **航班快照統計**（`cancellations.py`）：只有五個機場有來源，其他機場沒有統計，不用動；`flights.py` 不動
- **官方警報**：沒有 `warningSources` 的機場，`warnings: []`，而且第 4 節的 `official.warnings` 要是 `false`

### 4. `latest.json` 新欄位（契約；定稿要和 Duado spec 第 16 節一致）

- 頂層 `regions`：陣列，照顯示順序，每個 `{ "id": "taiwan", "name": { "zh-TW": "台灣", "zh-HK": "台灣", "zh-CN": "台湾", "en": "Taiwan" } }`
  （六個；zh-HK 的名稱用香港用字）
- `airports[].region`：地區 id
- `airports[].official`：物件，目前只有一個鍵 `{ "warnings": true|false }`——有沒有接官方警報來源（`warningSources`
  非空）。`false` 的機場網頁顯示「官方警報：尚未提供」。（欄位名照 Duado spec 第 16 節：`airports[].official.warnings`；
  和每格的 `slots[].official` 是不同層，不要搞混）
- `airports[].runwaySource` 不進 `latest.json`（只在 `airports.json`）
- `tests/test_build.py` 契約測試加這三個；README「輸出」範例與欄位說明補上
