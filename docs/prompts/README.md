# 給雲端對話的提示詞

主對話（HongThai 總指揮）每個功能寫一份，Shawn 開新的雲端對話貼「照 docs/prompts/<檔名> 做」。

- 檔名：`<日期>-<代號>-<名稱>.md`，例如 `2026-10-19-H5-cancel-stats.md`；代號接續 H 系列（H4 是第二階段）
- 只放文字：不放截圖內容、個資、金鑰、網址以外的任何憑證
- 開頭寫明要用的模型與強度（大功能 Opus 高；資料、文件類小 PR 用中）
- 碰到 `latest.json` 要加欄位時，提示詞裡把欄位名稱、型別、意思寫清楚，並要求同時更新
  `tests/test_build.py` 與 README 的「輸出」
- 固定結尾：

> 本機 `ruff check .`、`ruff format --check .`、`pytest -q` 全過才推，盡量一次推完。
> 開 PR 之後：`gh pr checks --watch` 等 CI，紅了自己修到綠（最多三輪），全綠時告訴我；
> 不要自己合併，我會先請主對話審查。

提示詞合併進 main 後就不再改；要修改做法就另開一份新的檔案。
